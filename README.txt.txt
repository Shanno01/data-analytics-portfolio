NORTHWIND SQL SALES ANALYTICS PROJECT

Project Overview:
This project analyzes sales data from the Northwind database using SQL.
The goal of the project is to generate business insights related to revenue, customers, products, employees, and sales trends.

Analysis Performed:
1. Overall Sales KPI Analysis
2. Top Customers Analysis
3. Top Products Analysis
4. Country-wise Sales Analysis
5. Employee Performance Analysis
6. Monthly Sales Trend Analysis
7. Customer Ranking using RANK()
8. Product Ranking using RANK()

SQL Skills Used:
- SQL JOINs
- Aggregate Functions (SUM, COUNT, AVG)
- GROUP BY
- ORDER BY
- DATE_FORMAT
- Window Functions (RANK)

Tools Used:
- MySQL Workbench
- SQL

Key Insights:
- Identified top revenue-generating customers
- Found best-selling products
- Analyzed sales growth trends over time
- Ranked customers and products based on revenue contribution
