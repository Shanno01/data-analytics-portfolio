# Excel Retail Sales Dashboard Project

## Overview
This project analyzes retail sales data using Microsoft Excel and interactive dashboard techniques to track business performance and generate insights.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Dashboard Design

## Dashboard Features
- Total Sales KPI
- Total Profit KPI
- Total Orders KPI
- Profit by Category analysis
- Sales by Region analysis
- Interactive Pivot Charts
- Retail Sales Dashboard

## Work Performed
- Cleaned and organized retail sales dataset
- Created Pivot Tables for business analysis
- Built Pivot Charts for visualization
- Designed an interactive sales dashboard
- Analyzed regional and category-wise performance
- Generated KPI reports for business monitoring

## Key Insights
- Identified top-performing product categories
- Compared regional sales performance
- Tracked overall sales and profit trends
- Highlighted important business KPIs




# SQL Northwind Sales Analysis Project

## Project Overview
This project analyzes sales data from the Northwind database using SQL to generate business insights related to revenue, customers, products, employees, and sales trends.

---

## Analysis Performed
1. Overall Sales KPI Analysis  
2. Top Customers Analysis  
3. Top Products Analysis  
4. Country-wise Sales Analysis  
5. Employee Performance Analysis  
6. Monthly Sales Trend Analysis  
7. Customer Ranking using RANK()  
8. Product Ranking using RANK()  

---

## SQL Skills Used
- SQL JOINs
- Aggregate Functions (SUM, COUNT, AVG)
- GROUP BY
- ORDER BY
- DATE_FORMAT
- Window Functions (RANK)
