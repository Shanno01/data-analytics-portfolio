# Excel Retail Sales Dashboard Project

## Overview
This project analyzes retail sales data using Microsoft Excel and interactive dashboard techniques to track business performance and generate insights.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Dashboard Design

## Dashboard Features
- Total Sales KPI
- Total Profit KPI
- Total Orders KPI
- Profit by Category analysis
- Sales by Region analysis
- Interactive Pivot Charts
- Retail Sales Dashboard

## Work Performed
- Cleaned and organized retail sales dataset
- Created Pivot Tables for business analysis
- Built Pivot Charts for visualization
- Designed an interactive sales dashboard
- Analyzed regional and category-wise performance
- Generated KPI reports for business monitoring

## Key Insights
- Identified top-performing product categories
- Compared regional sales performance
- Tracked overall sales and profit trends
- Highlighted important business KPIs

- Data Cleaning
- Data Analysis
- Dashboard Creation
- KPI Reporting
- Data Visualization
- Business Insights
